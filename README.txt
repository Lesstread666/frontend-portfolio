FRONTEND PORTFOLIO WEBSITE

---Project Overview---

This project is a multi-page frontend portfolio website
created as part of a frontend development assignment. The purpose of the
assignment was to demonstrate practical skills in HTML, CSS, JavaScript,
external libraries, API usage, accessibility, performance optimization,
and clean project structure.
The website presents personal information, projects, and contact details
in a clear, responsive, and visually consistent layout.


---Assignment Requirements---

-   Multi-page website (Home, Projects, About, Contact)
-   Semantic HTML structure using header, nav, main, section, and footer
-   External and modular CSS with shared variables
-   Responsive design using media queries
-   JavaScript DOM manipulation and event handling
-   Asynchronous data fetching using fetch()
-   External API integration (GitHub API)
-   Error handling and loading states
-   External libraries (jQuery and Font Awesome)
-   Animations and visual feedback
-   Accessibility best practices
-   Performance optimization and Lighthouse testing


---Technologies Used---

HTML5 CSS3 (CSS Variables, Flexbox, Responsive Design) JavaScript (ES6+)
jQuery GitHub REST API Font Awesome Git & GitHub

---Dynamic Content---

The Projects page dynamically fetches the latest project from the GitHub
API. The most recently created repository is displayed with formatted
title, description, GitHub link, and live demo if available. Loading and
error states are handled gracefully.


---Visual Effects---

Project cards fade in sequentially on page load. Hover effects include
glow and elevation. Social media icons scale and glow on hover. Smooth
transitions are implemented using CSS variables and jQuery.


---How to Run the Project---

Clone the repository and open index.html using a modern browser or Live
Server. No build tools or dependencies are required.
